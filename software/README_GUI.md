# JetAuto Pro 测试程序可视化界面

## 简介

本项目将原来的 `test.sh` 测试脚本转换为了可视化的GUI界面，使测试更加方便和直观。提供了两个版本：

1. **基础版** (`test_gui.py`)：依赖原始的 `test.sh` 脚本
2. **高级版** (`test_gui_advanced.py`)：直接执行命令，功能更强大

## 安装要求

- Ubuntu系统
- Python 3.x
- tkinter库（通常Ubuntu自带，如果没有请安装）

```bash
# 安装tkinter（如果需要）
sudo apt-get install python3-tk
```

## 使用方法

### 方法1：使用启动脚本

```bash
cd ~/software
./run_test_gui.sh
```

然后选择要运行的版本。

### 方法2：直接运行Python文件

```bash
# 运行基础版
python3 ~/software/test_gui.py

# 运行高级版（推荐）
python3 ~/software/test_gui_advanced.py
```

### 方法3：使用桌面快捷方式

1. 复制桌面文件到桌面：
```bash
cp ~/software/JetAuto_Test_GUI.desktop ~/Desktop/
chmod +x ~/Desktop/JetAuto_Test_GUI.desktop
```

2. 双击桌面上的"JetAuto Pro 测试程序"图标即可启动

## 功能特点

### 基础版功能
- 树形分类显示所有测试功能
- 一键运行测试
- 实时查看输出
- 停止所有进程
- 清空输出

### 高级版功能（推荐使用）
- 所有基础版功能
- **搜索功能**：快速查找测试项
- **多标签输出**：每个测试在独立标签页显示
- **命令预览**：运行前查看将要执行的命令
- **状态显示**：实时显示运行状态
- **历史记录**：自动保存运行历史
- **进程管理**：独立停止每个进程
- **双击运行**：双击即可快速运行测试

```
┌─────────────────────────────────────────────────┐
│              JetAuto Pro 测试程序               │
├─────────────────┬───────────────────────────────┤

│                 │         输出信息              │
```

### 操作流程

1. **选择功能**：在左侧树形列表中选择要运行的功能
2. **查看说明**：右侧会显示功能描述和命令预览
3. **运行测试**：点击"运行"按钮或双击功能项
4. **查看输出**：在输出标签页中查看实时输出
5. **停止进程**：可以停止当前进程或所有进程

## 功能分类

- **语音功能**：各种语音控制功能
- **软件工具**：Lab工具、图片采集、舵机控制等
- **无人驾驶**：YOLOv5检测、自动驾驶
- **OpenCV功能**：颜色检测、二维码、巡线
- **深度相机**：深度相机相关功能
- **三维建图导航**：RTAB-Map建图和导航
- **MediaPipe**：人体姿态、手势识别等
- **机械臂控制**：2D/3D视觉控制
- **YOLOv5**：模型训练相关
- **二维建图导航**：SLAM建图和导航
- **底盘控制**：IMU校准、控制器测试等

## 注意事项

1. 某些功能需要先启动深度相机
2. MediaPipe身体控制功能需要先关闭深度相机节点
3. 建图功能需要较长时间，请耐心等待
4. 运行前请确保ROS2环境已正确配置
5. 某些功能可能需要sudo权限

## 故障排除

### 问题：提示找不到tkinter模块
解决：安装tkinter
```bash
sudo apt-get install python3-tk
```

### 问题：命令执行失败
解决：
1. 检查ROS2环境是否正确配置
2. 确认相关软件包已安装
3. 查看输出中的错误信息

### 问题：无法停止进程
解决：
1. 使用"停止所有"按钮
2. 如果仍有问题，可以手动执行：
```bash
pkill -f gnome-terminal
```
